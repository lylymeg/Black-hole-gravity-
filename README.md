# 🕳️ Simulateur de Trou Noir & Lentille Gravitationnelle (Pygame)

Une simulation physique interactive de l'effet de **lentille gravitationnelle** (déviation de la lumière par la gravité selon la physique einsteinienne) développée en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🌌 **Déviation de la lumière :** Les faisceaux lumineux se courbent spectaculairement lorsqu'ils s'approchent du champ gravitationnel du trou noir.
- 🕳️ **Horizon des événements :** Les rayons qui passent trop près sont irrémédiablement aspirés dans le néant central.
- 🖱️ **Interactivité en temps réel :** Clique n'importe où sur l'écran pour déplacer instantanément le trou noir et observer la réaction immédiate du flux lumineux.
- ✨ **Disque d'accrétion :** Rendu visuel soigné avec un contour lumineux orangé imitant les représentations scientifiques.
